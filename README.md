# Business Analyst Portfolio — NovaBank Case Study

> **Fictitious data, for demonstration purposes only.**
> All companies, customers, accounts and transactions in this repository are
> entirely fictitious. "NovaBank" is an invented bank created to showcase
> Business Analysis deliverables.

Hello! I'm a **Junior Business Analyst / Functional Analyst** with hands-on
experience in **banking** (product operations, implementation and UAT). This
portfolio demonstrates an end-to-end BA workflow around a single fictional
feature — **Instant Transfers** at NovaBank — from requirements gathering and
UAT to SQL data analysis, process improvement and KPI reporting.

## Projects

| # | Project | What it shows |
|---|---------|---------------|
| 1 | [Requirements — Bank Feature](01-requirements-bank-feature/) | BRD, user stories (Gherkin), AS-IS/TO-BE process maps, RACI and traceability matrix for Instant Transfers. |
| 2 | [UAT Test Plan](02-uat-test-plan/) | Test case matrix, defect log, test results report and exit criteria for the Instant Transfers feature. |
| 3 | [SQL Transactions Analysis](03-sql-transactions-analysis/) | SQLite database of fictitious banking data plus 10–15 commented SQL queries (KPIs, suspicious fraud, retention, channels) and a findings report. |
| 4 | [Process Improvement](04-process-improvement/) | AS-IS/TO-BE analysis, root cause analysis (5 Whys / Ishikawa), before/after KPIs and an improvement proposal with estimated impact. |
| 5 | [KPI Dashboard](05-kpi-dashboard/) | Executive dashboard built with Python (pandas + matplotlib) over the dataset from Project 3, plus a one-page executive summary. |

## Skills demonstrated

- **Requirements analysis:** BRD writing, user stories, Gherkin acceptance criteria, traceability.
- **Process modelling:** Mermaid AS-IS / TO-BE diagrams, RACI matrices, root cause analysis.
- **UAT & QA:** test case design, defect tracking, test results reporting, exit criteria.
- **Data & SQL:** SQLite, SQL (aggregations, window functions, CTEs), pandas, data storytelling.
- **Reporting:** KPI definition, dashboards, executive summaries.
- **Tools:** Python, SQL, Excel (openpyxl), Markdown, Mermaid, Git.

# Portafolio de Business Analyst — Caso de Estudio NovaBank

> **Proyecto con datos ficticios, con fines demostrativos.**
> Todas las empresas, clientes, cuentas y transacciones de este repositorio son
> totalmente ficticias. "NovaBank" es un banco inventado creado para mostrar
> entregables de Business Analysis.

¡Hola! Soy **Analista Funcional Jr. / Business Analyst** con experiencia en
**banca** (operaciones de producto, implementación y pruebas UAT). Este
portafolio demuestra un flujo de trabajo completo de BA alrededor de una
funcionalidad ficticia — **transferencias instantáneas** en NovaBank — desde el
levantamiento de requisitos y el UAT hasta el análisis de datos con SQL, la
mejora de procesos y el reporte de KPIs.

## Proyectos

| # | Proyecto | Qué demuestra |
|---|----------|---------------|
| 1 | [Requisitos — Funcionalidad bancaria](01-requirements-bank-feature/) | BRD, historias de usuario (Gherkin), diagramas AS-IS/TO-BE, RACI y matriz de trazabilidad para transferencias instantáneas. |
| 2 | [Plan de pruebas UAT](02-uat-test-plan/) | Matriz de casos de prueba, registro de defectos, informe de resultados y criterios de salida. |
| 3 | [Análisis SQL de transacciones](03-sql-transactions-analysis/) | Base SQLite con datos bancarios ficticios más 10–15 consultas SQL comentadas (KPIs, fraude, retención, canales) y un informe de hallazgos. |
| 4 | [Mejora de procesos](04-process-improvement/) | Análisis AS-IS/TO-BE, análisis de causa raíz (5 Porqués / Ishikawa), KPIs antes/después y propuesta de mejora con impacto estimado. |
| 5 | [Tablero de KPIs](05-kpi-dashboard/) | Tablero ejecutivo con Python (pandas + matplotlib) sobre los datos del proyecto 3, más un resumen ejecutivo de una página. |

## Habilidades demostradas

- **Análisis de requisitos:** redacción de BRD, historias de usuario, criterios de aceptación en Gherkin, trazabilidad.
- **Modelado de procesos:** diagramas Mermaid AS-IS / TO-BE, matrices RACI, análisis de causa raíz.
- **UAT y QA:** diseño de casos de prueba, registro de defectos, informe de resultados, criterios de salida.
- **Datos y SQL:** SQLite, SQL (agregaciones, funciones de ventana, CTEs), pandas, narrativa de datos.
- **Reportes:** definición de KPIs, tableros, resúmenes ejecutivos.
- **Herramientas:** Python, SQL, Excel (openpyxl), Markdown, Mermaid, Git.
