# Project 3 — SQL Transactions Analysis (NovaBank)

> **Fictitious data, for demonstration purposes only.**
> NovaBank is an invented bank. Every customer, account and transaction in this
> project is synthetic and generated by script. No real data is used.

## Overview

This project builds a **SQLite database of fictitious banking data** and uses
**SQL** to answer business questions about the Instant Transfers feature from
Projects 1 and 2: KPIs, channel performance, suspicious fraud, retention and
segment behaviour. It ends with a findings report and business recommendations.

## Contents

| Artefact | Path | Description |
|----------|------|-------------|
| Data generator | [scripts/generate_data.py](scripts/generate_data.py) | Builds `data/novabank.db` (reproducible, fixed seed). |
| Database | [data/novabank.db](data/novabank.db) | SQLite database (3,000 customers · 5,000 accounts · 50,000 transfers). |
| Query runner | [scripts/run_queries.py](scripts/run_queries.py) | Executes every query in `sql/` and prints results. |
| SQL queries | [sql/](sql/) | 15 commented queries (KPIs, channels, fraud, retention, windows). |
| Findings report | [docs/findings-report.md](docs/findings-report.md) | Business findings and recommendations with real figures. |

## Data model

```
customers (customer_id PK, full_name, segment, city, country,
           birth_date, onboarding_date, status)
accounts  (account_id PK, customer_id FK, account_type, currency,
           balance, credit_limit, open_date, status, is_primary)
channels  (channel_id PK, channel_name, channel_group)
transactions (transaction_id PK, account_id FK, channel_id FK, direction,
              transfer_type, counterparty_name, counterparty_bank, is_internal,
              amount, currency, fee, status, failure_reason, fraud_score,
              is_flagged_fraud, created_at, settled_at, settlement_seconds)
```

## How to run

```powershell
# 1. Generate the database (reproducible)
python scripts/generate_data.py

# 2. Run all queries
python scripts/run_queries.py

# 3. Run only specific queries
python scripts/run_queries.py 03 08
```

## Sample findings

- Instant transfers settle in **~5 seconds, 100% under the 10 s target**.
- Only **87.2%** of transfers complete; **2,434** are stuck in "Pending".
- **2%** of transfers are flagged suspicious; **202k** of flagged value settled.
- **19%** of customers have never transacted.

See [docs/findings-report.md](docs/findings-report.md) for the full analysis.
